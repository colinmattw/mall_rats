# Catalogue

Every item is cosmetic. Nothing here changes speed, jump height, hitboxes, security pressure, pickup value or score multipliers. Starter pieces are free. Everything else is in the shop at a fixed price **and** eligible for mystery bags.

Looks (skin tone, hairstyle, hair color, face) are always free and are not catalogue items.

Incompatible tags: `fullHead` (sticker helmet) unequips `overEars` (headphones) when worn together.
